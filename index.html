🔧 GitHub 同步设置

填入你的 GitHub 个人访问令牌（PAT，创建时勾选 gist 权限）。令牌只存在你本机浏览器，不经过任何服务器。填好后，刷题/打卡/掌握状态会实时同步到你 GitHub 账号下的一个私有 Gist，手机流量、家里、单位任意网络都能用。

✅ 已接入公网云同步（GitHub 私有 Gist）：三个页面通过你自己的 GitHub 账号实现任意网络（单位 / 家里 / 手机流量）实时互通。 在上方「GitHub 同步设置」粘贴你的 Token 即可开启；数据存在你的私有 Gist（仅你的令牌可读），不经过任何第三方。
怎么选：通勤用手机流量刷/背、随手记状态；正式模考和错题三刷在电脑做，两边进度自动合并。
使用提示：① 手机/电脑浏览器打开本页面（CloudStudio 公网网址）；② 首次在「GitHub 同步设置」粘贴 Token；③ 建议添加到手机浏览器「主屏幕」，随时打开。
数据存于你的 GitHub 私有 Gist（你自己的账号，Token 仅存本机浏览器）
清浏览器缓存会丢失本机 Token，需重新粘贴；GitHub 账号里的 Gist 数据不受影响
